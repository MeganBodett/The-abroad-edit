A/B Test Plan — The Abroad Edit

Date: November 9, 2026

Page: Homepage (index.html)

Element being tested: The wording of one call-to-action (CTA) button or link.

Version A (Control): “Start Exploring”

Version B (Treatment): “Explore Destinations”

All other homepage elements, including images, layout, and content, will remain identical. The existing CTA wording will be verified before creating Version B.

Hypothesis: Version B will produce a higher percentage of “Yes” responses because “Explore Destinations” communicates more clearly what visitors can expect when selecting the link.

AI Model: GPT-6, using the same model and settings for every trial.

Visitor Persona: A college student considering studying abroad who is researching destinations and looking for helpful travel information.

Exact Prompt: “You are a college student considering studying abroad and researching potential destinations. Review the following webpage. Based only on this page, would you choose to explore the destinations section? Answer Yes or No, followed by one sentence explaining your decision.”

Random Assignment: Randomly assign trials to Version A or Version B before testing. Use a fresh conversation for each trial, with no memory of previous trials. Provide the corresponding complete page content in the same format for every trial.

Primary Outcome: Whether the AI visitor says they would explore the destinations section. Yes = 1; No = 0.

Sample Size: 100 trials total, with 50 trials per version. All trials will be completed regardless of the interim results.

Expected Completion Date: November 24, 2026. Version B will be launched no later than November 17.

Analysis: Calculate the proportion of Yes responses for each version, compare the difference in proportions, and use a two-proportion statistical test to assess whether the difference could be due to chance.

Hypothesis Support: The hypothesis will be supported if Version B has a higher Yes response rate than Version A, with statistical uncertainty reported.

SEO Protection: Version B will use a noindex directive and will not be included in the sitemap. The original homepage will remain the indexed version.

Limitations: AI-generated intentions are not actual website clicks or real student behavior, so results will not establish how human visitors would respond.
